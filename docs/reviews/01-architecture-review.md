# تقرير مراجعة البنية المعمارية

> التاريخ: 2026-08-09 — الحالة: ✅ **معتمدة** (بملاحظات غير حاجبة)

## 1. نطاق المراجعة

مراجعة بنية النظام بعد إكمال جميع الوحدات: الخادم (`server/`)، لوحات المسؤول/الوكيل/المزوّد، تطبيق الزبون نحو الجوال (`customer-mobile/`)، والحزمة المشتركة (`shared/`)، إضافة إلى طبقة النشر (`deploy/`).

## 3. معمارية الخادم

- **طبقات واضحة:** `routes/*.js` (26 ملف) → `middleware/*` (auth/rbac/error) → `utils/*` (jwt/password/helpers/log/push/uploads/response) → `db/` (غلاف `get/all/run/transaction` + هجرات + بذور).
- **لا ORM:** SQL خام مع استعلامات معلمة بالكامل عبر غلاف موحّد، ما يسهّل استبدال طبقة التخزين لاحقاً.
- **عزل قاعدة البيانات في طبقة واحدة:** أي انتقال لاحق إلى Worker Thread أو Postgres يتم من `db/index.js` دون لمس المسارات (قرار موثّق في `docs/system-analysis.md` §10).
- **محور النطاق (Governorate Scope):** هوية النطاق تأتي من الخادم حصراً — `orderScope/scopeClause/ensureCanManage` تُقيّد كل استعلام حسب `req.user.governorate_id` (وكيل) أو `req.user.provider_id` (مزوّد) أو `req.user.id` (زبون). لا تعتمد الواجهات على أي تقييد من طرفها.
- **سلسلة العمل:** محافظة ← وكيل (1:1 مع إجارة) ← مزوّدون ← طلبات ← عمولات (منصة/وكيل/مزوّد) ← محافظ وسحوبات.

## 5. واجهات الويب

- **نموذج SPA** متطابق في اللوحات الأربع مع `react-router`، تصميم عربي RTL موحّد عبر `shared/styles.css` و`ui.jsx`.
- **تطبيق الزبون:** مكوّن للجوال أولاً (شريط سفلي، بحث لاصق، سلة دائمة في `localStorage`، طلب مستقل لكل مزوّد بمفتاح Idempotency). قابل للترقية إلى Capacitor/Expo بنفس كود React.
- **تقسيم الشيفرة:** تطبيق الزبون مقسّم عبر التحميل الكسول (lazy routes).
- **إشعارات:** Service Worker مشترك (`shared/sw.js`) مسجَّل في اللوحات، وWeb Push عبر VAPID مولّد محلياً.

## 6. النشر والتشغيل

- **`deploy/`:** إعدادات nginx (رؤوس كاش مضبوطة) وتوثيق نشر التحديثات بحيث يصل التحديث تلقائياً للزبائن.
- **تشغيلي:** WAL checkpoint + نسخ احتياطي `VACUUM INTO` كل ساعة (7 نسخ)، تدوير `activity_log` (90 يوم)، تدوير سجلات الملفات (10MB × 3)، إعادة محاولة `SQLITE_BUSY`.
- **حراسة الإنتاج:** رفض الإقلاع بجلسة إنتاج و`JWT_SECRET` افتراضي، تحقق في الإنتاج (اختبارات `production-guards`).

## 8. الملاحظات غير الحاجبة

1. `promotions.js` (486 سطراً) يجمع مسارات المزوّد والمسؤول والعام في ملف واحد — يُوصى بالفصل عند النمو.
2. استبدال `localStorage` بالتوكن بـ HttpOnly cookie مؤجل (موثّق) — غير حاجب حاليّاً.
3. مخزن معدّل الطلبات في الذاكرة لا يصلح لتعدّد المثيلات (يُعالج عند التوسع بـ Redis).
4. الوثيقة المرجعية `system-analysis.md` أقدم من الوحدات الأخيرة (كوبونات/مفضلة/سحوبات/إعلانات) — يُنصح بتحديثها لتعكس الحالة الحالية.
