# سوق الرافدين — منصة سوق إلكتروني عراقي

منصة سوق إلكتروني مستوحاة من سوق علي بابا الصيني، تعمل في **18 محافظة عراقية بشكل منفصل**، وتضم 5 خدمات تعمل عبر مزودي الخدمة فقط (بدون أي خدمات أخرى):

| # | الخدمة | الوصف |
|---|--------|-------|
| 1 | 🛒 المتاجر | متاجر متعددة لبيع المنتجات والبضائع |
| 2 | 🍽️ المطاعم | مطاعم لطلب الوجبات والطعام |
| 3 | 🏨 الفنادق | فنادق لحجز الغرف والإقامة |
| 4 | ✈️ حجز الطيران | حجز تذاكر الطيران المحلي والدولي |
| 5 | 🧳 مكاتب السفر | مكاتب سفر للرحلات والباقات السياحية |

## نموذج العمل

- **المنصة وسيط فقط** بين الزبون ومزود الخدمة مقابل **نسبة عمولة** للمنصة والوكيل.
- **لا توفر المنصة خدمة التوصيل** ولا مندوبين ولا تتبع طلبات — **التوصيل وتتبع الطلبات مسؤولية مزود الخدمة بالكامل**.
- كل محافظة لها **وكيل واحد** يدير جميع مزودي الخدمة في محافظته دون غيرها.
- الوكيل **يجب أن يجدد إجارة الوكالة السنوية** بمبلغ يحدده المسؤول حسب كل محافظة.
- توزيع العمولات على الطلب: `عمولة المنصة + عمولة الوكيل` تُخصمان من إجمالي الطلب، ويستلم المزود الباقي.

## هيكل المشروع

```
D:\1h1h
├── server/          # الواجهة الخلفية (Node.js + Express + SQLite)
├── admin-panel/     # لوحة إدارة المسؤول (React + Vite) — المنفذ 5175
├── agent-panel/     # لوحة وكلاء المحافظات (React + Vite) — المنفذ 5174
├── provider-panel/  # لوحات مزودي الخدمة الخمس (React + Vite) — المنفذ 5176
├── customer-mobile/ # واجهة الزبون نحو الجوال أولاً (React + Vite) — المنفذ 5173
└── shared/          # كود مشترك بين اللوحات الأربع (إعداد Vite، عميل API، إشعارات، مكوّنات UI)
```

> **توحيد اللوحات عبر `shared/`:** اللوحات الأربع تستورد كل الكود المشترك من الحزمة
> `@rafidain/shared` بدل تكراره. يشمل ذلك: إعداد البناء الموحّد (`shared/vite.base.js`)،
> عميل API الافتراضي (`shared/src/default-api.ts`)، وإدارة إشعارات الدفع
> (`shared/src/default-push.ts`)، ومكوّنات الواجهة (`@rafidain/shared/ui`). كل لوحة
> أصبحت "رفيعية" (thin) تستورد من `shared/` — فأي إصلاح أمني أو تحسين يُطبَّق في مكان واحد.

## المتطلبات

- Node.js 23+ (يستخدم وحدة `node:sqlite` المدمجة — بدون تثبيت قاعدة بيانات)
- npm

## التشغيل

```bash
# 1) تثبيت جميع الاعتماديات
npm run setup

# 2) تهيئة قاعدة البيانات وإدخال البيانات الأولية (18 محافظة، 5 خدمات، حسابات تجريبية)
npm run seed

# 3) تشغيل الخادم واللوحات (5 نوافذ أو أوامر)
npm run server    # API على http://localhost:4001
npm run admin     # لوحة المسؤول على http://localhost:5175
npm run agent     # لوحة الوكيل على http://localhost:5174
npm run provider  # لوحة مزود الخدمة على http://localhost:5176
npm run customer  # واجهة الزبون على http://localhost:5173
```

> ملاحظة: إذا كان المنفذ 4001 مشغولاً عدّله في `server/.env` (انسخ `server/.env.example` إلى `server/.env` أولاً).

## لوحة إدارة المسؤول (admin-panel — منفذ 5175)

دخول حصري للمسؤول فقط، مع تحكم كامل:

- **لوحة المعلومات**: إحصائيات المنصة، الإيرادات، الطلبات حسب الحالة، المزودون حسب الخدمة، الحركة الشهرية
- **المحافظات**: إضافة/تعديل/حذف/تشغيل/إيقاف المحافظات الثمانية عشرة + تحديد **رسوم إجارة الوكالة السنوية** لكل محافظة
- **وكلاء المحافظات**: إضافة وكيل واحد لكل محافظة، تعديل، إيقاف، حذف، تعيين نسبة العمولة، **تجديد الإجارة**، عرض الدفعات، إعادة تعيين كلمة المرور
- **مزودو الخدمة**: إضافة/تعديل/حذف/تشغيل/إيقاف/توثيق المزودين + تعيين نسبة عمولة المنصة لكل مزود + تصفية حسب المحافظة ونوع الخدمة
- **الخدمات**: تشغيل/إيقاف/إضافة/تعديل/حذف الخدمات الخمس
- **الطلبات**: عرض جميع الطلبات، **إنشاء طلب بالنيابة عن زبون (بنود حرة + اختيار الزبون من الحسابات)**، تغيير الحالات، تفاصيل توزيع العمولات
- **الزبائن**: إدارة حسابات الزبائن
- **العمولات**: نسب المنصة والوكيل الافتراضية + مثال توضيحي للتوزيع
- **محافظ المزودين**: محافظ مزودي الخدمة (الرصيد/الحركات)، **طلبات الشحن المسبق** (معاينة لقطة الإثبات، موافقة تُشحن تلقائياً، رفض بسبب)، شحن يدوي استثنائي، وعدّاد طلبات معلّقة مع **تنبيه صوتي** عند وصول طلب شحن جديد
- **إجارات الوكالات**: الموافقة/رفض طلبات تجديد إجارة الوكلاء
- **سجل النشاط**: جميع العمليات المنفذة في النظام
- **الإعدادات**: اسم المنصة، العملة، رقم الدعم، **حسابات استقبال الشحن (زين كاش/آسيا باي/مصرف العراق الأول/المصرف الأهلي) وتعليمات الشحن**
- **ملفي الشخصي**: تغيير كلمة المرور

## لوحة الوكلاء (agent-panel — منفذ 5174)

دخول حصري للوكلاء فقط، يتحكم الوكيل **بمحافظته دون غيرها**:

- **لوحة المعلومات**: إحصائيات محافظة الوكيل فقط + حالة إجارته
- **مزودو الخدمة في المحافظة**: إضافة/تعديل/حذف/تشغيل/إيقاف/توثيق مزودي محافظته فقط (تفرضه الواجهة الخلفية)
- **طلبات المحافظة**: جميع طلبات مزودي محافظته + **إنشاء طلب بزبون حرّ (اسم/هاتف) لمزوّد في محافظته فقط (تُفرض خلفياً)** + تغيير الحالات
- **عمولاتي**: أرباح الوكيل الشهرية وأعلى المزودين مساهمة
- **إجارة الوكالة**: عرض حالتها، سجل الدفعات، و**إرسال طلب التجديد السنوي** (يوافق عليه المسؤول)
- **ملفي الشخصي**: تغيير كلمة المرور

## لوحة مزودي الخدمة (provider-panel — منفذ 5176)

نظام **5 لوحات في تطبيق واحد**، تُعرض اللوحة حسب نوع خدمة المزود عند تسجيل الدخول:

| نوع الخدمة | لوحة المعلومات | الفهرس | إضافات |
|-----------|----------------|--------|--------|
| 🛒 المتاجر | نعم | المنتجات (سعر، خصم، مخزون، صور) | أقسام المنتجات + **العروض والتخفيضات** |
| 🍽️ المطاعم | نعم | قائمة الطعام (أصناف، أسعار، صور) | أقسام القائمة + التوفر الفوري |
| 🏨 الفنادق | نعم | الغرف (نوع، سعر ليلة، نزلاء، صور) | **الحجوزات** |
| ✈️ الطيران | نعم | الرحلات (رقم، شركة، مسار، مواعيد، مقاعد) | **الحجوزات** |
| 🧳 مكاتب السفر | نعم | الباقات (وجهة، أيام، مكونات، صور) | **الحجوزات** |

ميزات مشتركة:
- **لوحة المعلومات**: إيرادات المزود (صافي الإيراد بعد العمولة)، الطلبات حسب الحالة، الإيراد الشهري، آخر الطلبات
- **الفهرس**: إضافة/تعديل/حذف/تشغيل/إيقاف، بحث، تصفية حسب القسم (للمتاجر والمطاعم)
- **الطلبات**: طلبات المزود فقط مع تغيير الحالات (التوصيل والتتبع مسؤولية المزود) + **زر القبول** (يخصم عمولة المحفظة) و**الرفض بسبب**
- **محفظتي**: الرصيد، **الشحن المسبق** (دفع لطريقة من القنوات ← رفع لقطة إثبات ← موافقة المسؤول تُشحن تلقائياً)، قائمة طلبات الشحن بالحالة/السبب، ودفتر الحركات
- **الملف الشخصي**: بيانات النشاط + تغيير كلمة المرور
- **الأمان**: لا يمكن للمزود تعديل فهرس مزود آخر، وكل الأقسام مقيدة بنوع خدمته (تُفرض خلفياً)

| الطريقة | المسار | الوصف |

## واجهة الزبون (customer-mobile — منفذ 5173)

واجهة ويب **نحو الجوال أولاً** مستوحاة من هوية علي بابا/علي إكسبريس (برتقالي `#ff4747`، شريط سفلي، بحث لاصق)، مبنية بـ React 18 + Vite 5، والواجهة الخلفية لها جاهزة بالكامل على `:4001/api`:

| POST | `/api/orders` | إنشاء طلب مع حساب العمولات تلقائياً + حجز (فندق/طيران/سفر) |
| PUT | `/api/orders/:id/status` | تغيير الحالة؛ الزبون: إلغاء فقط قبل بدء التنفيذ |

سير عمل التطبيق: اختيار المحافظة ← الخدمات ← المزودون ← الفهرس ← سلة/حجز ← إتمام الطلب ← تتبع طلباته (مع إمكانية الإلغاء قبل بدء التنفيذ).

> **ميزات إضافية مُنفّذة في واجهة الزبون (غير مذكورة أعلاه):** برنامج **الولاء والإحالة** (`Loyalty.tsx`/`Referral.tsx`)، **الكوبونات** (`Coupons.tsx`) و**دفتر العناوين** (`Addresses.tsx`)، **المتابعة والمفضلة** (`FollowContext`/`FavoritesContext`)، **العروض والصفقات** (`FlashDeals`/`AdsRow`/`ShareSheet`/`Banner`)، **تقييمات العناصر** (`ItemReviews.tsx`)، و**شريط تتبّع الشحن/الطلب** (`ShippingProgress.tsx`). الخادم محوّل بالكامل إلى **TypeScript** (`server/src/**/*.ts`) مع طبقة `services/` مستخرجة.
